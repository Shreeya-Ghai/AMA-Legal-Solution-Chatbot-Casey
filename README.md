# Casey – AMA Legal Solutions Chatbot 

Casey is a rule-based chatbot developed to streamline client interactions for AMA Legal Solutions by providing quick and structured responses to common legal queries.

## Features
- Instant responses to legal queries
- 24/7 accessibility
- Reduces response delays
- Improves client satisfaction

## Tech Stack
- HTML, CSS, JavaScript
- Python (Backend)
- CSV (Data Storage)

##  Project Structure
- app.py
- check.html
- script.js
- style.css
- user_data.csv
